# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability
ScorpionXploit adheres to coordinated vulnerability disclosure. If you identify a security defect, please do NOT file a public issue.
Send an email to: **aditya08sharma@gmail.com** with reproducible steps and proof-of-concept.
